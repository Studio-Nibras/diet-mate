# DietMate - Design System & UI Guidelines

---

# Overview

DietMate mengusung gaya desain **Modern Organic Minimalism**, yaitu perpaduan antara desain minimalis modern dengan nuansa alami yang identik dengan makanan sehat, gaya hidup sehat, dan wellness.

Referensi style mengarah pada website yang memiliki karakter:

- Clean
- Soft
- Premium
- Elegant
- Organic
- Fresh
- Friendly
- Spacious

Website harus memberikan kesan bahwa pengguna sedang menggunakan produk startup kesehatan modern, bukan website rumah sakit ataupun blog diet biasa.

# UI Principles

Selalu gunakan

- White Space
- Simple Layout
- Rounded Element
- Soft Color
- Friendly Icon
- Clean Typography

Jangan menggunakan

- Border tebal
- Warna mencolok
- Terlalu banyak gradient
- Card yang sempit
- Layout terlalu padat

---

# Overall Experience

DietMate harus terasa seperti aplikasi startup kesehatan modern.

Ketika pengguna membuka website, mereka harus merasakan pengalaman yang:

- Fresh
- Calm
- Premium
- Personal
- Trustworthy

Bukan seperti website informasi diet biasa, melainkan platform digital yang mendampingi perjalanan hidup sehat pengguna dari assessment hingga progress harian.
